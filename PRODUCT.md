# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

HTML, CSS e JavaScript estáticos; sem dependências em runtime.

## Product Purpose

Gerar senhas de forma moderna e prática para o usuário, com código publicado em um repositório na sua conta GitHub. O usuário solicitou somente o repositório, sem GitHub Pages.

## Capabilities and Constraints

Geração criptográfica local, comprimento e categorias configuráveis, cópia e interface responsiva. O usuário solicitou modos com palavras, símbolos permitidos configuráveis, perfis rápidos e preferências lembradas. A direção atual solicitada é uma interface mais limpa, com base cinza e azul discreto, menos informações e alinhamentos consistentes. Preferências são persistidas localmente com allowlist; senhas nunca são persistidas. Sem backend. Público presumido: pessoas que precisam gerar uma senha para uma conta.
