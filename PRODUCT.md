# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

HTML, CSS e JavaScript estáticos; sem dependências em runtime.

## Product Purpose

Gerar senhas de forma moderna e prática para o usuário, com código publicado em um repositório na sua conta GitHub. O usuário solicitou somente o repositório, sem GitHub Pages.

## Capabilities and Constraints

Escolhas de implementação: geração criptográfica local, comprimento e categorias configuráveis, cópia e interface responsiva. Sem backend ou persistência de senhas. Público presumido: pessoas que precisam gerar uma senha para uma conta.
